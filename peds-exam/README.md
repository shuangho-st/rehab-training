# 兒科題庫前後測

住院醫師兒科測驗的題庫與前測／後測系統。分成兩條路，共用同一份題庫內容：

| | 網頁版（本資料夾） | Google 表單版（`gas/`） |
|---|---|---|
| 學員作答 | 手機／電腦開連結作答，可看附圖 | Google 表單 |
| 出卷 | `admin.html` 抽題 → 前測、後測兩個連結＋QR code | 試算表選單「題庫系統」 |
| 成績 | 自動送到試算表「網頁作答」，`admin.html` 看報表 | 表單回應 → 六張報表、詳解講義 |
| 附圖題 | ✅ 可以 | ❌ 表單看不到圖，已排除 |

## 檔案

```

  common.js           抽題、連結編碼、配對 t 檢定、報表計算

  data/bank-114-specialty-A.json   114 年兒科專科醫師筆試甄審 A 卷，100 題
  img/                附圖（第 12、23、78 題）
  gas/前後測後端.gs                 網頁版的後端（收成績、給教師端讀）
  gas/兒科題庫測驗系統_完整版.gs     Google 表單版主程式 v18（支援 A–E 五選項）
```

## 題庫：114 年度兒科專科醫師筆試甄審（A 卷）

- 來源：社團法人臺灣兒科醫學會試題與答案紙，100 題，五選一。正解直接取自答案紙，未更動。
- 正解分布：A 13、B 19、C 23、D 30、E 15
- 科別（沿用表單版的 12 科）：General 22、ID 12、Hema/Onco 8、Neuro 7、Genetic 7、NB 7、CV 7、Nephro 7、AIR 7、GI 6、Endocrine 6、Chest 4
- 年分欄填 `114專科`，和國考的 `114` 分開，抽題時可以單獨篩選。
- 兒少保護（21–25、65）、急診重症（42–49）、青少年（66–68）題目另外標了 `topic`，科別仍歸在 General／ID，因為表單版沒有這幾科。

**科別判斷沒把握、請複核的題目**：3 發展篩檢（General／Neuro）、9–10 代謝與新生兒篩檢（Genetic／NB）、
16 周產期中風（Neuro／NB）、34 缺鐵（Hema／General）、46 氣胸（Chest）、66 青少年性病（ID／General）、
85 氣喘急性發作（Chest／AIR）、97 咽後膿瘍（ID／Chest）、99 BPD（Chest／NB）。改 JSON 裡的 `category` 即可。

**答案請留意**：第 7 題（法定傳染病「截至 2025 年 8 月」）有時效性；第 95 題（維生素 D 上限）
與部分國外指引的數字不同。都照答案紙，沒有更動，講評時可以補充。

## 部署

### 1. 網頁

這個資料夾是純靜態網頁，跟著 repo 一起放在 GitHub Pages 就好。合併進 Pages 使用的分支後網址是
`https://<帳號>.github.io/rehab-training/peds-exam/`（教師端是 `…/peds-exam/admin.html`）。

### 2. 成績後端（約 5 分鐘）

1. 開一份 Google 試算表（可以就用表單版那一份）→「擴充功能」→「Apps Script」
2. 新增檔案，貼上 `gas/前後測後端.gs`，把最上面 `WEB.ADMIN_KEY` 改成你自己的密碼，存檔
3. 函式下拉選單選 `WEB_setup` → 執行（走完授權：進階 → 前往（不安全）→ 允許）
4. 「部署」→「新增部署作業」→ 網頁應用程式；執行身分「我」、存取權「所有人」
5. 把得到的 `…/exec` 網址貼進 `config.js` 的 `API_URL`，commit、push

之後改了後端程式，要「管理部署作業」→ 編輯 → 版本選「新版本」，網址才會沿用。

`前後測後端.gs` 只有 `doGet`、`doPost` 和 `WEB_` 開頭的函式，跟表單版主程式放在同一個專案不會衝突。

## 一梯次怎麼跑（網頁版）

1. `admin.html` → 出卷：選題數與科別配比 → 抽題 → 填梯次名稱 → 產生連結
2. 發**前測**連結（或投影 QR code）。前測預設不公布正解
3. `admin.html` → 成績報表 → 輸入管理密碼 → 選梯次：看科別答對率與逐題「主要誤選」決定教什麼
4. 教學後發**後測**連結（題目相同，每人順序打亂；預設交卷後公布正解與逐題檢討）
5. 再看報表：配對 t 檢定、每人進步、「扣掉整體進步」、逐題前後對照；可匯出 CSV

- 前後測靠「Email 或員工編號」配對，學員兩次要填一樣。
- 同一人重複交卷時以第一次為準。
- 連結裡帶的是題號清單，前後測連結的題號完全一樣，所以一定是同一卷；報表會檢查卷別碼。
- 作答中途關掉頁面，重開同一個連結會接著寫；沒網路時成績先存在裝置上，連線後自動補傳。
- 題庫 JSON 放在公開網站上，懂技術的人找得到正解。這是形成性評量用的，不適合需要保密的正式考試。

**解讀提醒**（也寫在報表頁上）：用前測最弱的科別決定教什麼可以；但每科只有兩三題，
最弱科在後測「進步」大多是迴歸平均。判斷教學效果看整體分數、「扣掉整體進步」那一欄，或逐題前後對照。

## Google 表單版：匯入 114 專科題目

1. 先把試算表專案裡的主程式換成 `gas/兒科題庫測驗系統_完整版.gs`（v18）。
   v17 只認得 A–D，五選項的題目在 v17 會被健檢判成「選項拆不開」。v18 四選項、五選項都可以。
2. 新增檔案貼上 `gas/匯入114專科題目.gs` → 執行 `import114Specialty` → 確認視窗按「是」
3. 跑「① 題庫健檢」，再「重新抽題」；年分輸入 `114專科` 就只抽這份
4. 匯入檔可以刪掉

第 12（家族譜）、23（X 光）、78（臨床照片）題有附圖，Google 表單看不到圖，沒有匯入；網頁版有這三題。

### v18 改了什麼（相對 v17）

- `splitQuestion`、`normalizeLetter` 認得 A–E，四選項題目的行為不變
- 題庫健檢多一項「正解對不到選項」（例如正解 E 但只有四個選項）
- 逐題分析多一欄 E；打亂選項時依新位置重編 A–E
- `FORMCFG.FOLDER_ID` 預設留空（留空就不搬資料夾、不跳警告）

## 新增題庫

把題目整理成 `data/bank-114-specialty-A.json` 的格式（`no`、`stem`、`options`、`answer`、`category`，
附圖放 `img/` 並填 `image`），在 `data/banks.json` 登記一筆即可。要同步到表單版：

```bash
python3 tools/make_import_gs.py --from-bank data/<新題庫>.json "" <函式後綴> > gas/匯入<…>.gs
```
